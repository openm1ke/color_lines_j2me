# Color Lines J2ME

«Цветные линии» для CLDC 1.1 / MIDP 2.0: перемещай шары по свободным клеткам
и собирай линии из пяти и более шаров одного цвета. Есть анимации перемещения,
удаления линий и подскока выбранного шара, Undo и рекорды для разных правил.

## Сборка и запуск

Нужны **JDK 21** и **Python 3**. Системный Ant и старый JDK не требуются.
Из корня проекта:

```sh
./antw run        # собрать и открыть FreeJ2ME: 240×320, увеличение ×2
./antw package    # создать dist/lines.jar и dist/lines.jad
./antw test       # проверить сборку, игровые сценарии, настройки и аудио
./antw clean      # удалить build/ и dist/
```

Альтернативный вызов: `python3 antw run`. Первый запуск скачивает Ant 1.10.15
и Eclipse Compiler 3.26.0 с Maven Central в `tools/build/`, проверяя SHA-256.
После загрузки сборка работает без сети. `JAVA_HOME`, если задан, должен
указывать на JDK. J2ME API, FreeJ2ME и ProGuard уже включены в репозиторий.

Компилятор проверяет исходники как Java 1.3 и создаёт Java 1.1 bytecode против
CLDC/MIDP API. ProGuard выполняет CLDC preverification. JAD содержит профиль
MIDP-2.0 и актуальный размер JAR. Обычный современный `javac` не подходит для
этих параметров. Для системного Ant после загрузки инструментов:

```sh
ant -lib tools/build/ecj-3.26.0.jar package
```

Название, версия и MIDlet задаются в `local.properties`. Разрешение и масштаб:

```sh
./antw -Demulator.width=240 -Demulator.height=320 -Demulator.scale=3 run
```

Перед повторным запуском или очисткой закрой старое окно эмулятора: открытый
JAR на NTFS может мешать удалению `dist/`. Hot reload и отладка J2ME не настроены.

## Редактирование в OpenIDEA

Открой корень проекта. Конфигурации в `.openidea/run.toml`:

- **Lines — FreeJ2ME 240x320** — сборка и запуск;
- **Lines — Build JAR + JAD** — сборка;
- **Lines — Check** — проверки;
- **Lines — Clean** — очистка.

Для автодополнения и переходов нужен Eclipse JDT Language Server (JDK 21+),
выбранный в настройках OpenIDEA. `.project` и `.classpath` задают `src/` и два
J2ME API JAR; эмулятор и ProGuard не входят в classpath приложения. Уровень
Java 8 в `.settings/` нужен современному серверу редактора; настоящая сборка
проверяет Java 1.3 и CLDC. После изменения метаданных переоткрой проект.

## Управление

- Стрелки — перемещение курсора, выбор пункта меню или значения настройки.
- Enter — START, выбор шара и клетки назначения, изменение настройки.
- Q — левая софт-клавиша: Select / Undo / Save.
- W — правая софт-клавиша: Menu в игре, Back в настройках, Exit в главном меню.
- NumPad 1 — Undo во время игры.
- Мышь — выбор клеток, пунктов меню и экранных софт-клавиш.

Привязки можно изменить в Settings эмулятора. В FreeJ2ME Q означает левую
софт-клавишу; в исходнике также есть обработка буквенного кода `q` для выхода.

## Настройки и рекорды

В **SETTINGS** доступны все семь настроек на одном экране 240×320:

| Настройка | Значения |
| --- | --- |
| Board | 7×7, 9×9, 11×11 |
| Colors | 3–7 |
| New balls | 1–3 новых шара после хода без линии |
| Music | On / Off |
| Music volume | 0–100%, шаг 5% |
| Effects | On / Off |
| Effects volume | 0–100%, шаг 5% |

Музыка и эффекты имеют независимые выключатели и уровни громкости.
Изменения звука слышны сразу. **Save** сохраняет настройки и возвращает в меню;
**Back** отменяет изменения, включая предпрослушанную громкость. При ошибке
сохранения экран остаётся открытым с предупреждением.

Правила применяются к **NEW GAME**. **RESUME** продолжает старую партию с
прежними параметрами. Стартовый режим: 9×9, 5 цветов, 3 новых шара. Для
спокойной игры попробуй 9×9, 4 цвета и 1–2 новых шара. Линия требует минимум
5 шаров при любом размере поля. Занятая игроком клетка предпросмотра не
уничтожает запланированный шар: он переносится в другую свободную клетку.

В **STATISTICS** сохраняется лучший результат отдельно для каждой из 45
комбинаций правил, с указанием размера поля, числа цветов и новых шаров.
Рекорд обновляется сразу при начислении очков; Undo его не стирает. Данные
хранятся в RMS данного MIDlet на устройстве, без облачной синхронизации.
Обновление формата настроек сохраняет старые рекорды. В FreeJ2ME записи
находятся в `rms/`; удаление этого каталога сбросит настройки и результаты.

Каждая новая партия получает новый seed; Undo восстанавливает случайную
последовательность. История ограничена 128 снимками — до 127 отмен.

## Музыка и эффекты

**Minigame soundtrack — Kirard**, исходный MIDI (~50 КБ, 4:10):
[страница автора на OpenGameArt](https://opengameart.org/content/minigame-soundtrack).
Лицензия [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Файл не изменён; сведения включены в `res/music/LICENSE.txt` и ABOUT.
Музыка изначально выключена, громкость 35%. MIDI зациклен; его тембр зависит
от синтезатора телефона или эмулятора.

**Pop sounds — EZduzziteh**, три варианта pop1/pop2/pop3:
[источник](https://opengameart.org/content/pop-sounds-0),
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Оригиналы stereo 44.1 kHz преобразованы в mono PCM WAV 16 kHz/16 bit:
2–4 КБ на эффект, 0,06–0,13 секунды. Сведения о преобразовании включены в
`res/sfx/LICENSE.txt` и ABOUT. Эффекты изначально включены, громкость 70%.
Один короткий pop запускается при начале удаления линии; варианты чередуются,
не меняя игровой RNG и не накладываясь в громкий залп.

Медиа загружается в отдельных потоках, останавливается на паузе и освобождается
при выходе. Ноль отключает соответствующий звук. Недоступное аудио не прерывает
игру; настройки показывают предупреждение.

## Проверки и устройство проекта

`./antw test` проверяет метаданные и ресурсы JAR/JAD, версию байткода, CLDC
StackMap и отсутствие встроенных классов J2ME API. Игровые проверки работают
с настоящим кодом и MIDP-реализацией FreeJ2ME:

- все 45 режимов, границы поля, появление шаров и удаление линий;
- первый ход и Undo, перенос занятых предпросмотров, восстановление RNG;
- ограничение истории и освобождение снимков;
- очередь ввода, одновременные события, паузу, возобновление и Exit;
- RMS: перезагрузку, повреждённые данные и миграцию формата;
- независимую громкость, mute/unmute, отключение эффектов и отказ аудио;
- отдельные действия Save/Back для клавиш и мыши;
- изменение кадров bounce без изменения игрового состояния.

Тесты используют отдельное RMS-хранилище `lines-automated-check`, не затрагивая
пользовательские рекорды. Снимки экранов записываются в `build/previews/`.
Проверки не заменяют полное прохождение игры на телефоне.

Исходники находятся в `src/lines/`, ресурсы — в `res/`, тесты — в `tests/`.
Ввод, Undo, правила, анимация и отрисовка обрабатываются игровым потоком;
колбэки передают запросы через очередь на 32 события. Пауза очищает очередь,
а Exit может остановить игру независимо от анимации и заполнения очереди.

`build/`, `dist/`, `tools/build/`, `rms/`, `config/`, `freej2me_system/` и
личное состояние IDE исключены из Git. Общие конфигурации редактора и запуска,
исходники, тесты, аудиоресурсы и их лицензии включены в репозиторий.

Оригинальная Color Lines разработана Олегом Дёминым, Геннадием Денисовым и
Игорем Ивкиным и издана Gamos в 1992 году. J2ME-версия: openm1ke.

WAV-эффекты используют простой 44-байтовый заголовок PCM без LIST/INFO:
WAV-декодер включённой версии FreeJ2ME не умеет пропускать эти метаданные.
При загрузке поток буферизуется для поддержки mark/reset. Тесты декодируют
все эффекты непосредственно из JAR через FreeJ2ME и проверяют длительность
и ненулевой PCM-сигнал, не требуя аудиоустройства.
